# Commax RS485 Poller (UDP)

월패드 없이 RS485 버스를 유지하기 위한 **최소 기능** 애드온.

HA 연동·상태 파싱은 담당하지 않습니다.
EW11에 UDP로 주기적으로 각 기기에 상태 조회 패킷만 전송합니다.

UDP는 비연결형이라 "동시접속 슬롯" 개념이 없어, 기존에 EW11 TCP 채널을
쓰는 다른 월패드 연동 애드온(예: Homenet2MQTT)과 연결 경합 없이 동시에 운영할 수 있습니다.

## 동작 방식

월패드가 없으면 RS485 버스에 마스터가 없어 기기들이 상태를 응답하지 않습니다.
이 애드온이 월패드 대신 마스터 역할을 해 버스를 활성 상태로 유지합니다.

```
[이 애드온]
    │
    │ 폴링 패킷 전송 (UDP, 연결 없음, 주기적)
    ▼
  EW11 (UDP Server) ──► RS485 버스 ──► 기기들 (조명, 난방, 가스 …)
                              ◄────────────────── 상태 응답
```

상태 응답은 EW11을 통해 버스에 흐르며,
다른 HA 연동 앱(Homenet2MQTT 등)이 이를 수신해 처리합니다.

## 설정

| 이름 | 기본값 | 설명 |
|:--|:--|:--|
| `elfin_server` | — | EW11 IP 주소 |
| `elfin_udp_port` | `9999` | EW11 UDP 포트 |
| `poll_interval` | `5` | 전체 기기 폴링 주기 (초) |

## 기기 정보 파일

`/apps/devinfo.json`에 폴링할 기기 목록(이름, 개수, 응답 prefix)을 정의합니다.
직접 수정해서 댁의 기기 구성에 맞게 조정하세요.

## EW11 설정

기존에 TCP Server 소켓을 쓰고 있다면 그대로 두고, EW11 관리 페이지에서
**소켓을 추가**(+Add)해 UDP 채널을 별도로 구성합니다.

- Protocol: **Udp Server**
- Local Port: `9999` (위 `elfin_udp_port`와 동일하게)
- Route: Uart (RS485)
